# Changelog

All notable changes to AlaCraft are documented here.  
The project has been live at [alacraft.day](https://alacraft.day) since November 2023.

---

## 2026

- **Community Portal** — players can now publish posts, react, and interact directly on the site
- **Japanese locale** — added 7th language (`/ja/`), including official Mojang block name translations
- **New tools** — Nether calculator, Fireworks builder, Tellraw generator, Flat World generator
- **Contact page** — direct way to reach the AlaCraft team
- **Block SEO pages** — 1,300+ individual block pages with multilingual descriptions go live
- **Sitemap** — automated XML sitemap with hreflang per locale (1,300+ URLs indexed)

## 2025

- **News section** — Minecraft news and server updates published regularly
- **Block reference** — full database of 1,332 blocks with search and filtering
- **Multilingual expansion** — Ukrainian, Spanish, French, German locales added
- **Player profiles** — personal inventory tracking and activity history

## 2024

- **Armor calculator** — visual armor rating tool with interactive 3D skin preview (July)
- **Skin viewer** — browse and preview Minecraft skins (May)
- **MOTD generator** — create custom server messages with color formatting (April)
- **Color codes tool** — full Minecraft color and formatting reference (March)
- **Privacy Policy & Terms of Service** — added (January–February)
- **Crafting recipes database** — 753 recipes searchable by item name and ingredient
- **Russian and English locales** — first two supported languages

## 2023

- **Domain registered** — `alacraft.day` registered November 3, 2023
- **Soft launch** — homepage goes live November 26, 2023
- **Core platform** — Laravel + Vue 3 stack, MySQL database, Cloudflare CDN
- **Crafts foundation** — initial import of Minecraft crafting recipe database
