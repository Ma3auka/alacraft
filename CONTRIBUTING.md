# Contributing to AlaCraft

Thank you for your interest in AlaCraft! We welcome feedback, bug reports, and ideas from the community.

## How to contribute

### Found a bug?
1. Check if it's already reported in [Issues](https://github.com/Ma3auka/alacraft/issues)
2. If not — open a new Issue using the **Bug Report** template
3. Or join our [Discord](https://discord.gg/QbSEPbGA8u) and report it in the `#bug-reports` channel

### Have a feature idea?
1. Open a new Issue using the **Feature Request** template
2. Describe what you'd like to see and why it would be useful
3. We review all suggestions — popular ideas get prioritized

### Want to help with translations?
AlaCraft currently supports 7 languages: English, Russian, Ukrainian, Spanish, French, German, and Japanese.  
If you spot a translation error or want to suggest improvements, contact us via Discord.

### Want to suggest content?
- Missing crafting recipe? → [Discord](https://discord.gg/QbSEPbGA8u)
- Incorrect block description? → Open an Issue
- Missing Minecraft version? → Open an Issue

## Community guidelines

- Be respectful to other players and contributors
- Write in English in Issues so everyone can follow the discussion
- No spam, self-promotion, or off-topic content
